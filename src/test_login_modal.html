🔐 Login Modal Integration Test

Test Scenario: Free User Chat Limit Reached

Step 1: Start Chat as Anonymous User

• Open the chat interface without logging in

• Send your first message

Expected: Message counter should show "Free messages remaining: 4"

Step 2: Use Up Free Messages

• Continue sending messages (5 total)

• Watch the counter decrease: 4 → 3 → 2 → 1 → 0

Expected: When remaining = 2 or less, show "Sign in for unlimited access" hint

Step 3: Trigger Login Modal

• Send the 6th message (should exceed limit)

Expected:
  • ❌ NO upgrade modal should appear
  • ✅ LOGIN MODAL should appear with:
  •    • Title: "Continue Chatting"
  •    • Message: "You've used all your free messages! Sign in or create an account..."
  •    • Toggle between "Sign In" and "Register" tabs

Step 4: Test Login Functionality

• Try logging in with valid credentials

Expected:
  • ✅ Modal should close automatically
  • ✅ User should now be authenticated
  • ✅ Chat should work with unlimited access

Step 5: Test Registration

• Close modal and trigger limit again

• Click "Register" tab in modal

• Fill out registration form

Expected:
  • ✅ Registration form should have: email, username, password, confirm password
  • ✅ Form validation should work
  • ✅ Successful registration should close modal and authenticate user

🚀 How to Run This Test

  1. Start the backend server: cd WelthWestServer2 && python run.py
  2. Start the frontend server: cd WelthWestClientSharing && npm start
  3. Open browser and navigate to the AI chat page
  4. Follow the test steps above

✅ Success Criteria

  • Free users see login modal (not upgrade modal) when limit reached
  • Modal has both login and registration functionality
  • Successful authentication closes modal and enables unlimited chat
  • UI shows proper messaging and counter for free users
